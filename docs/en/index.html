ESP32 HX711 Precision Scale: Build a Wheatstone Bridge Digital Scale

Build a digital weighing scale with an ESP32, HX711, and 5 kg Wheatstone bridge load cell. Wiring, PlatformIO setup, LCD, and calibration. The ESP32 hosts its own Wi-Fi network and displays live readings in a tablet browser. No internet connection is needed.

Build and calibrate

  1. Copy the password template firmware/wifi_local.example.h → firmware/wifi_local.h. Set your local Wi-Fi password.
  2. Build with PlatformIO: pio run -d firmware -e terazi_main.
  3. Leave the platform empty for startup tare. Join the HassasTerazi network and open 192.168.4.1 in your browser.
  4. Calibrate with a known mass, then check against a different known mass.

How the Wheatstone bridge works

Load changes the resistance of the strain gauges in the bridge. The HX711 digitizes the differential output, and the ESP32 subtracts the zero reference and converts the result to grams using calibration.
